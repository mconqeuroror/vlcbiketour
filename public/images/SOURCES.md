## License obligations summary
- **CC BY / CC BY-SA** require: author credit, license name + link, link to the source,
  and a note if changes were made (these files were resized/recompressed — state
  "cropped/resized from original" if displayed).
- **CC BY-SA** additionally requires that any adapted/derivative image be shared under
  the same license. Displaying the photo on the website unmodified (aside from resizing)
  does not make the website itself subject to ShareAlike, but any edited derivative
  of the image would be.
- Keep this file in the repository as the provenance record.
