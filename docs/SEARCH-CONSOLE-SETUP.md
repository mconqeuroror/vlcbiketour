# Google Search Console setup — biketourvlc.com

Checklist for the operator. Nothing here guarantees indexing or rankings — Search Console only reports what Google does; indexing and ranking remain Google's decision.

## 1. Verify the domain (DNS, recommended)

1. Open https://search.google.com/search-console → Add property → **Domain** property: `biketourvlc.com`.
2. GSC shows a `google-site-verification=...` TXT record.
3. Add that TXT record at the DNS provider for `biketourvlc.com` (at the zone apex).
4. Wait for DNS propagation (minutes to hours), then click **Verify** in GSC.

The domain property covers both `https://biketourvlc.com` and any subdomain, and both EN/ES trees. If DNS access is not available, use the URL-prefix property `https://biketourvlc.com/` with the HTML file or meta tag method instead — but then add the property again per protocol/host variant if they ever change.

## 2. Submit the sitemap

1. In the verified property: **Indexing → Sitemaps**.
2. Submit `https://biketourvlc.com/sitemap.xml`.
3. Confirm the status flips to "Success" and the discovered-URL count matches the expected count: 11 static pages + 2 guide articles = 13 paths × 2 locales = 26 URLs.

The sitemap is generated by `src/app/sitemap.ts` and includes per-URL `xhtml:link` alternates (en, es, x-default → en). robots.txt at `/robots.txt` points to the same sitemap and disallows only `/api/`.

## 3. Monitor hreflang / international coverage

- **Indexing → Pages**: check that EN and ES versions of each page are indexed, and that no page reports "Duplicate without user-selected canonical" or "Alternate page with proper canonical tag" unexpectedly (the latter is normal only for genuine alternates).
- Each localized page emits a self-referencing canonical plus reciprocal `hreflang` (en, es, x-default) via `buildMetadata` in `src/lib/seo/metadata.ts`. If GSC reports hreflang errors ("no return tags"), check that both locales of the affected page are live and that the alternates in `buildMetadata` resolve.
- Confirm `/` redirects or serves `/en/` deterministically (no IP/browser-language redirects — `localeDetection: false` in `src/i18n/routing.ts`).

## 4. Request indexing for launch

- Use **URL Inspection** on the 26 canonical URLs and request indexing for the homepage and tour page first.
- Expect days to weeks for a new domain; this is normal and not an error state.

## 5. Google Business Profile (separate from Search Console)

A Business Profile can help local discovery but requires real, verifiable business details that are currently **missing**:

- Operator legal name and address (currently `null` in `src/config/operator.ts`).
- A real phone number and email.
- A physical location or service-area definition Google can verify (postcard/phone/video verification).

Do **not** create a profile with placeholder data — unverifiable profiles get suspended and can harm the domain's trust. Wait for `docs/OWNER-INPUT-CHECKLIST.md` items to be filled.

## 6. Ongoing

- Check **Performance** monthly for query/page data; feed findings into `docs/KEYWORD-MAP.md` (real queries only — do not invent volumes).
- Watch **Page Experience / Core Web Vitals** once field data exists.
- No guarantees: submitting a sitemap and verifying a property do not promise indexing, impressions, or any ranking position.
